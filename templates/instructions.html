Google Sheets API Credentials Missing

Your application is configured to run using the Google Sheets API. To connect successfully, follow these steps:

  1. Go to the Google Cloud Console and generate a Service Account JSON Key.
  2. Rename the key to credentials.json and save it in the root folder of the project.
  3. Open your Google Sheet, click Share, and add the Service Account's email address as an Editor.
  4. Restart the Flask web server.
